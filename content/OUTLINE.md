# 16-week outline

Month labels:
- Weeks 1–4: Month 1 — Computer fundamentals, HTML and CSS
- Weeks 5–8: Month 2 — CSS layout, JavaScript and problem solving
- Weeks 9–12: Month 3 — Web interactivity, Git and React
- Weeks 13–16: Month 4 — Backend, databases and full-stack development

Two lessons per week. Session numbers are continuous from 1 to 32.

## Week 1 — Introduction to computers and software development
Module slug `week-01-computers`. Lessons `understanding-computers` (session 1) and `internet-and-tools` (session 2).
Assignment: identify software and practise computer navigation. Quiz slug `week-01-quiz`.

Session 1 teaches: what a computer is; hardware and software; what software means; applications; websites; mobile applications; what software developers do; types of developers; frontend; backend; full-stack; how software affects everyday life.
Practice: identify five everyday applications, explain each, identify websites and mobile apps, discuss what happens when a person uses an application.
Homework: a short document explaining five applications. submissionKind lesson_response.

Session 2 teaches: the internet; a website; a browser; a domain name; a server; a web address; basic client-server communication; a text editor; Visual Studio Code; computer navigation; files and folders; creating and saving files.
Practice: open a browser, visit sites, create a learning folder, create and save a file, open the folder in Visual Studio Code. Include install guidance but say VS Code can wait if session 1 already said tools come when needed. This session is when VS Code is introduced, with Windows, macOS, and Linux steps.
Homework points at the module assignment.

## Week 2 — HTML fundamentals
Module `week-02-html`. Lessons `introduction-to-html` (3), `html-text-links-images-lists` (4).
Assignment: personal introduction webpage.

Session 3: what HTML means; why it exists; elements; tags; opening and closing tags; attributes; document structure; DOCTYPE; html; head; body; title. Practice: first HTML webpage.
Session 4: headings; paragraphs; bold and emphasis; links; images; alternative text; ordered and unordered lists; divisions; semantic HTML introduction. Practice: personal introduction page. Homework: webpage about a hobby, via the module assignment.

## Week 3 — HTML forms and semantic structure
Module `week-03-html-structure`. Lessons `html-forms` (5), `semantic-html` (6).
Assignment: contact page with a form and semantic sections.

Session 5: forms; form elements; inputs; labels; buttons; text, email, password, number; radio; checkbox; select; textarea; required; basic HTML validation. Practice: registration form.
Session 6: semantic HTML; header; nav; main; section; article; aside; footer; why semantics matter; basic accessibility; HTML best practices. Practice: multi-section page.

## Week 4 — CSS fundamentals
Module `week-04-css`. Lessons `introduction-to-css` (7), `css-box-model` (8).
Assignment: styled profile card.

Session 7: what CSS is; why pages need it; syntax; selectors; properties; values; inline, internal, external CSS; connecting CSS; colours; backgrounds; fonts; text. Practice: style an HTML page.
Session 8: width; height; margin; padding; borders; radius; the box model; content; border-box; display; block; inline; inline-block. Practice: profile card.

## Week 5 — CSS layout and responsive design
Module `week-05-layout`. Lessons `flexbox` (9), `grid-and-responsive-design` (10).
Assignment: responsive landing page.

Session 9: what layout means; why layout systems exist; flex containers and items; display flex; justify-content; align-items; flex-direction; flex-wrap; gap. Practice: navigation bar and card layout.
Session 10: CSS Grid; rows and columns; gaps; responsive design; mobile-first; media queries; breakpoints; relative units; responsive images; testing screen sizes. Practice: responsive landing page. Homework: make an existing page work on mobile, tablet, and desktop.

## Week 6 — Introduction to JavaScript
Module `week-06-javascript`. Lessons `programming-and-javascript` (11), `variables-types-operators` (12).
Assignment: shopping total calculator.

Session 11: what programming means; programming languages; what JavaScript does; how it works with HTML and CSS; developer tools; console; first statement; comments; statements; basic syntax. Practice: output in the console.
Session 12: variables; let; const; naming; strings; numbers; booleans; null; undefined; types; arithmetic, assignment, comparison, and logical operators; concatenation and template literals. Practice: calculator expressions. Homework: shopping total calculator.

## Week 7 — Conditions, loops, and functions
Module `week-07-control-flow`. Lessons `conditions` (13), `loops-and-functions` (14).
Assignment: grade calculator or number guessing game using functions.

Session 13: Boolean logic; comparisons; if; else; else if; nested conditions; AND; OR; NOT; a first look at the ternary operator; decision problems. Practice: age checker and grading calculator.
Session 14: why loops exist; for; while; conditions; increment and decrement; function declarations and calls; parameters; arguments; return values; scope introduction. Practice: reusable calculation functions.

## Week 8 — Arrays, objects, and problem solving
Module `week-08-collections`. Lessons `arrays-and-objects` (15), `array-methods-and-problem-solving` (16).
Assignment: shopping list or student score manager.

Session 15: arrays; indexes; length; reading and changing items; adding and removing; objects; properties and values; arrays of objects. Practice: small student records programme.
Session 16: forEach; map; filter; find; findIndex; basic sorting; breaking down problems; pseudocode; testing; reading errors; debugging. Practice: task list with arrays and objects.

## Week 9 — DOM and browser interaction
Module `week-09-dom`. Lessons `understanding-the-dom` (17), `events-and-interaction` (18).
Assignment: interactive page, with the homework counter as the graded piece or a DOM exercise. Use an interactive counter or to-do as the assignment.

Session 17: what the DOM is; HTML as a document; querySelector; getElementById; reading content; changing text, attributes, classes, and styles; textContent; careful use of innerHTML. Practice: page where JavaScript changes headings and content.
Session 18: events; click; input; submit; listeners; event objects; preventDefault; basic form validation; updating the DOM. Practice: to-do list or form validation. Homework: counter with increase, decrease, and reset.

## Week 10 — Git and GitHub
Module `week-10-git`. Lessons `version-control-and-git` (19), `github-and-sharing` (20).
Assignment: GitHub repository containing earlier projects and a README.

Session 19: why versions matter; version control; Git; installation for Windows, macOS, and Linux; terminal basics; navigating folders; git init; status; add; commit; log; commit messages.
Session 20: what GitHub is; Git versus GitHub; account; repositories; local and remote; connecting; push; pull; clone; README; basic collaboration. Practice: upload HTML, CSS, and JavaScript projects.

## Week 11 — TypeScript and React introduction
Module `week-11-typescript-react`. Lessons `introduction-to-typescript` (21), `react-components` (22).
Assignment: TypeScript exercises plus a React component application. Do not assume prior TypeScript knowledge.

Session 21: what TypeScript is; why it is used; JavaScript versus TypeScript; annotations; string, number, boolean, arrays, objects; parameter and return types; inference; basic interfaces and type aliases.
Session 22: what React is; why it is used; user interfaces; components; reusable components; JSX; Vite setup; React with TypeScript; running the app; project structure. Practice: header, profile, and footer components. OS-specific terminal steps for npm.

## Week 12 — React fundamentals
Module `week-12-react-state`. Lessons `props-state-events` (23), `lists-forms-and-tasks` (24).
Assignment: React task list with a form and an empty state.

Session 23: props; passing information; state; useState; updating state; re-rendering; click events. Practice: counter and profile component.
Session 24: lists; map; keys; conditional rendering; controlled inputs; form submission; validation; component organisation. Practice: task list with add, complete, and delete.

## Week 13 — Backend fundamentals
Module `week-13-backend`. Lessons `backend-and-nodejs` (25), `http-and-a-simple-server` (26).
Assignment: a Node.js server with one JSON endpoint. Use Express for the beginner path. Mention NestJS only as a later, more structured option. Do not teach both in depth.

Session 25: backend; frontend versus backend; client-server; Node.js; JavaScript outside the browser; installation on Windows, macOS, and Linux; npm; packages; package.json; creating and running a project.
Session 26: servers; HTTP; requests and responses; methods; status codes; headers; JSON; a simple Express server; one endpoint. Practice: endpoint returning JSON.

## Week 14 — APIs and backend logic
Module `week-14-apis`. Lessons `rest-apis` (27), `validation-and-frontend-integration` (28).
Assignment: a basic API consumed by a frontend.

Session 27: what an API is; how applications communicate; REST; resources; endpoints; GET, POST, PUT, PATCH, DELETE; JSON; status codes; testing with the browser or a simple documented tool such as the REST Client idea explained without requiring a paid product. Practice: task endpoints.
Session 28: request body; route parameters; query parameters; basic validation; error handling; HTTP errors; connecting React with fetch; loading and error states. Practice: connect the task list to the API.

## Week 15 — Databases and SQL
Module `week-15-databases`. Lessons `databases-and-postgresql` (29), `sql-operations` (30).
Assignment: a simple database for tasks or student records.

Session 29: what a database is; why apps need one; relational databases; PostgreSQL; tables, rows, columns, records; data types; primary keys; foreign keys; relationships; installing PostgreSQL on Windows, macOS, and Linux; a database client.
Session 30: SQL; creating databases and tables; insert, read, update, delete; SELECT, INSERT, UPDATE, DELETE, WHERE, ORDER BY; a basic join if the explanation stays small. Practice: task table CRUD.

## Week 16 — Full-stack project and review
Module `week-16-capstone`. Lessons `guided-fullstack-task-app` (31), `testing-deployment-review` (32).
Assignment: guided task manager. Include projectGuide with database structure, API guidance, component guidance, and a testing checklist. Beginner scope only.

Session 31 builds a task manager with React, TypeScript, Node.js, Express, REST, and PostgreSQL. Features: view, add, edit, delete, complete, save in the database, connect the frontend, handle basic errors. Teach how the pieces connect. Do not demand production architecture.
Session 32: why testing matters; manual testing; debugging; environment variables; what deployment means; hosting frontend, backend, and database at a conceptual level; basic security awareness; README; demonstration; course review; where to study next. No job promise.

Every lesson file is `content/weeks/weekNN.ts` and exports `weekNN`.
Assignment slugs: `week-01-assignment` through `week-16-assignment`, using two digits.
Quiz slugs: `week-01-quiz` through `week-16-quiz`.
